# Craft files

The `.craft` files of the career's missions, as KSP loads them. Each one was generated by the helper mod
from the JSON spec of the same name in `crafts/` and launched in the career from this exact file.

## Using them
Copy the files you want into `saves/<your save>/Ships/VAB/` and open them from the VAB's load dialog.

- KSP 1.12.5, stock parts only. No DLC and no part mods are needed.
- The newer files carry a `KOSNameTag` module on every part. kRPC's ModuleManager patch adds it; a game
  without kRPC should skip it with a warning in the log (not checked on a clean install).
- In a career save the parts must be researched first, and the big ones need an upgraded pad and VAB.
- They were built to be flown by a script: no action groups, no fairings, and the staging assumes the
  order in the spec (`stage` 1 fires at launch). Check the staging before you fly one by hand.
- Results, Δv and what went wrong with each design are in `LOG.md` and `docs/record/career.json`.

## Older files
The files written before 2026-09-26 carry no `MODULE` data, because the builder did not save it yet. KSP
fills in the part defaults when it loads them, and they flew that way, but loading them in the VAB editor
has not been checked:

Duna 1, Hopper 1, Keo Relay 1, Keo Relay 2, Minmus Flyby 1, Minmus Lander 1, Minmus Science 1,
Mun Lander 1 to 7, Mun Tanker 1, Orbiter 1, Pad Lab, Polar Relay 1, Rescue 1, Rescue 2, Salvage 1 to 3,
Sounding 2, Sounding 3.
